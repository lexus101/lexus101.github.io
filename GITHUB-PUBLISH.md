# Publish Leo Portfolio on GitHub Pages

Target repository: `lexus101/lexus101.github.io`

1. Create a **public** repository named exactly `lexus101.github.io` and initialize it with a README.
2. Upload/push the contents of this folder to the repository root (`index.html` must stay at the root).
3. In GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Select the default branch (`main`) and folder `/(root)`, then Save.
5. The site URL will be `https://lexus101.github.io/`.

`.nojekyll` is included because this is a hand-built static site and does not need Jekyll processing.
